## Privacy

This repository is public. Personal finance records, balances, bank-statement details, debt values, account identifiers and private emails are intentionally not committed.

The standalone backup stores data entered in the browser with `localStorage`. Live ChatGPT Site data is separate.

## Run

Open `index.html`, or publish the repository with GitHub Pages.

## Backup note

The available ChatGPT Sites export surface exposes the project/version metadata and rendered projection, but not the original generated source tree as a downloadable archive. This backup is therefore a standalone recoverable app shell that preserves the wallet structure and project/version identifiers without leaking private financial data.
